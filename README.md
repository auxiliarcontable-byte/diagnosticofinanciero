# Diagnóstico Financiero

Sistema de Diagnóstico Financiero para MiPyMES, publicado con Cloudflare Workers (recursos estáticos).

- **En línea:** https://diagnosticofinanciero.auxiliarcontable.workers.dev
- **Versión publicada:** v3.1 (`public/index.html`). Proyecto completo, historial de versiones y pruebas: [GEMELO-DIGITAL-FIANCIERO](https://github.com/auxiliarcontable-byte/GEMELO-DIGITAL-FIANCIERO).
- **Versión anterior:** `archivo/index_anterior_2026-10-12.html` (fuera de `public/`, no se publica).

Cada commit a `main` se despliega automáticamente. Los datos que captura cada usuario se guardan solo en su navegador; al abrir la v3.1 por primera vez, los datos de la versión anterior se migran automáticamente.
